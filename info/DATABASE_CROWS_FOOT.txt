[ENTITA: user]
  <PK> id              INTEGER (auto-increment)
      username         VARCHAR(255) <U>
      email            VARCHAR(255) <U>
      tax_id_code     VARCHAR(16) <U> (not null)
      full_name       VARCHAR(200) (not null)
      date_of_birth   DATE (not null)
      gender          VARCHAR(1) (not null)
      birth_city_country VARCHAR(200) (not null)
      phone_number     VARCHAR(20) <U> (nullable)
      password         VARCHAR(255) (not null)
      active           BOOLEAN (default TRUE)
      fs_uniquifier    VARCHAR(64) <U> (not null, default uuid4 hex)
  RELAZIONI:
    1 --- N  group_memberships  (via group_memberships.user_id -> user.id)
    1 --- N  rider_shifts      (via rider_shifts.user_id -> user.id)
    1 --- N  fall_events       (via fall_events.user_id -> user.id)
    1 --- N  sos_contacts      (via sos_contacts.user_id -> user.id)
    N --- M  role              (via roles_users.user_id / role_id)

[ENTITA: role]
  <PK> id              INTEGER (auto-increment)
      name             VARCHAR(80) <U>
      description      VARCHAR(255)
  RELAZIONI:
    1 --- N  user              (via roles_users.role_id -> role.id)

[ENTITA: roles_users]  (tabella intermedia / association)
  <FK> user_id         INTEGER (PK, FK -> user.id)
  <FK> role_id         INTEGER (PK, FK -> role.id)
  RELAZIONI:
    N --- M  user              (user_id)
    N --- M  role              (role_id)

[ENTITA: groups]
  <PK> id              INTEGER (auto-increment)
      name             VARCHAR(100) (not null)
      description      VARCHAR(255) (nullable)
      code             VARCHAR(12) <U> (not null, indexed)
      security_token   VARCHAR(64) <U> (nullable, indexed)
      created_at       TIMESTAMP (default now, not null)
  RELAZIONI:
    1 --- N  group_memberships  (via group_memberships.group_id -> groups.id)

[ENTITA: group_memberships]  (tabella intermedia / association RBAC)
  <PK> user_id         INTEGER (PK, FK -> user.id)
  <PK> group_id        INTEGER (PK, FK -> groups.id)
      role             VARCHAR(20) (default 'member', not null)
      joined_at        TIMESTAMP (default now, not null)
  RELAZIONI:
    N --- M  user              (user_id)

[ENTITA: rider_shifts]  (metadati turno GPS)

[ENTITA: fall_events]  (eventi caduta confermati)

      latitude        FLOAT (not null)

  RELAZIONI:
    N --- 1  user              (user_id)

[ENTITA: sos_contacts]  (contatti emergenza)

      relationship     VARCHAR(50) (nullable)

      created_at      TIMESTAMP (default now, not null)

    N --- 1  user              (user_id)

================================================================================
  CARDINALITA' / RELAZIONI (CROW'S FOOT VISIVO)
================================================================================

user ||---O< group_memberships >O---|| groups
      (1 user ha 0..N memberships)  (1 gruppo ha 0..N memberships)
      PK: user.id                  PK: groups.id
      FK: group_memberships.user_id -> user.id
      FK: group_memberships.group_id -> groups.id
      ATTRIBUTI ASSOCIAZIONE: role, joined_at

user ||---O< roles_users >O---|| role
      (1 user ha 0..N ruoli)    (1 ruolo assegnato a 0..N utenti)
      PK: roles_users.user_id + role_id
      FK: roles_users.user_id -> user.id
      FK: roles_users.role_id -> role.id

user ||---O< rider_shifts >O---|| (nessuna entita' aggiuntiva; relazione 1:N diretta)
      (1 user ha 0..N shift)
      FK: rider_shifts.user_id -> user.id

user ||---O< fall_events >O---|| (nessuna entita' aggiuntiva; relazione 1:N diretta)
      (1 user ha 0..N fall_events)
      FK: fall_events.user_id -> user.id

user ||---O< sos_contacts >O---|| (nessuna entita' aggiuntiva; relazione 1:N diretta)
      (1 user ha 0..N sos_contacts)
      FK: sos_contacts.user_id -> user.id

================================================================================
  NOTE TECNICHE (REDIS / FLASK / FASTAPI / WORKER)
================================================================================

- user.id (INTEGER, PK) coincide con user_id nel payload FastAPI (str coerente).
- group_memberships.role determina RBAC (owner / admin / member).
- rider_shifts.gpx_path punta al file .gpx generato dal worker (GPXStreamManager).
- fall_events.timestamp usa to_timestamp(timestamp_ms / 1000.0) nel worker.
- Nessun campo sensore grezzo (acc_x, gyro, heading) persiste nel DB: solo metadati turno ed eventi caduta.
- Redis (redis_client, TTL 90s) memorizza solo position:{user_id} (ultimo punto GPS), non una tabella DB.
- Autenticazione condivisa: `/auth/check_session` verifica cookie `session` Flask; FastAPI (`verify_flask_session`) chiama questo endpoint e sovrascrive `user_id` nel payload (`binding`) con `session["user_id"]`, impedendo `impersonation`.
